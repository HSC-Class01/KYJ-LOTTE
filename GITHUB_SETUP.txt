GITHUB DEPLOYMENT CHECKLIST
1. Upload all files and folders in this ZIP to the root of HSC-Class01/KYJ-LOTTE.
2. Create .github/workflows in GitHub if needed.
3. Copy github-workflows-template/update-dart.yml to .github/workflows/update-dart.yml.
4. Add repository secret DART_API_KEY (OpenDART API key).
5. Settings > Pages > Build and deployment > Source: GitHub Actions.
6. Settings > Actions > General > Workflow permissions: Read and write permissions.
7. Actions > Update LOTTE DART data > Run workflow.
8. About > edit the repository description/website URL to https://hsc-class01.github.io/KYJ-LOTTE/
The ZIP intentionally contains no dotfiles/dotfolders. The workflow template is in a visible folder and must be copied to the required .github/workflows path after upload.
